# AlgorithmDesign

A collection of implementations, experiments, and problem-solving exercises developed while studying **Algorithm Design**.

This repository contains the algorithms and problems I have studied and implemented throughout the course. Each directory represents a different topic or problem and contains the corresponding implementation or experiment.

The goal of this repository is not only to collect algorithm implementations, but also to keep track of my progress and practical work throughout the course.

## 1. Sorting

The sorting section contains implementations of several well-known sorting algorithms:

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort
- Heap Sort

These implementations are used to study different sorting strategies and compare their behavior and complexity.

## 2. Linear Algebra

The Linear Algebra section contains implementations related to matrices, including:

- REF — Row Echelon Form
- RREF — Reduced Row Echelon Form
- Matrix Inverse
- Invertible Matrix

This section focuses on implementing the underlying operations rather than relying entirely on external libraries.

## 3. Random

This section contains work related to randomized algorithms and random-based algorithmic experiments.

The purpose of this section is to explore how randomness can be incorporated into algorithmic solutions and problem solving.

---

## 4. Hanoi

This section contains an implementation of the **Tower of Hanoi** problem.

The problem is useful for studying:

- Recursion
- Recursive problem decomposition
- State transitions
- Algorithmic complexity

---

## 5. DFS

This section focuses on **Depth-First Search (DFS)**.

DFS is a fundamental graph traversal technique and an important building block for many graph algorithms.

---

## 6. Binary Search

This section contains work related to **Binary Search**.

Binary Search demonstrates how a problem can be reduced by repeatedly eliminating half of the remaining search space.

---

## 7. Kole Poshti

This section contains the implementation and algorithmic work related to the **Kole Poshti** problem.

The problem is included as part of the practical exercises and problem-solving work developed during the course.

---

## 8. WEPEL

**WEPEL** stands for **Weighted External Path Length**.

This section contains the implementation and related work for calculating and working with weighted external path lengths.

This concept is closely related to tree structures and is also relevant to the study of Huffman coding.

---

## 9. Huffman

This section contains work related to **Huffman Coding**.

Huffman coding is a lossless compression technique based on constructing a weighted binary tree and assigning shorter codes to more frequent symbols.

The implementation provides practical experience with:

- Binary Trees
- Priority-based selection
- Greedy algorithms
- Tree construction
- Prefix codes

---

## 10. Chess

The Chess section contains algorithmic work related to the game of Chess.

This section is included as a practical application of algorithmic thinking to a more complex problem domain.
